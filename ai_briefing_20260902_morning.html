Hugging Face 发布 207 个 WebGPU 内核与 Fleet 基准工具 Hugging Face Releases 207 WebGPU Kernels and Fleet Benchmarking Suite
Open Research
Hugging Face WebAI 团队于 9 月 1 日发布 @huggingface/kernels 库与首批 207 个优化 WebGPU 内核，托管在 huggingface.co/webgpu-kernels，采用 Apache 2.0 许可。每个内核以独立仓库形式提供，包含 manifest.json、正确性测试、基准测试用例与参数化 WGSL 着色器模板，形成可版本化、可验证的软件工件。同步推出的 Fleet 工具可在用户浏览器中运行内核测试，众包真实设备上的性能与正确性证据。在 Apple M4 上与 ONNX Runtime Web 开发版对比的 809 个可比较用例中，HF 内核几何平均快 2.57 倍、中位数快 1.90 倍，其中 Add、Softmax、LayerNormalization 等常见算子均有明显提升。
Hugging Face's WebAI team released the @huggingface/kernels library and an initial collection of 207 optimized WebGPU kernels on September 1, hosted at huggingface.co/webgpu-kernels under Apache 2.0. Each kernel is packaged as an independent repository containing a manifest.json, correctness tests, benchmark cases, and parameterized WGSL shader templates—treating shaders as versioned, verifiable software artifacts. The accompanying Fleet tool runs kernel tests inside users' browsers to crowdsource performance and correctness evidence across real devices. On an Apple M4 against ONNX Runtime Web dev builds, HF kernels were 2.57× faster by geometric mean and 1.90× faster by median across 809 comparable cases, with gains on Add, Softmax, and LayerNormalization.
Why it matters · 关键看点

Browser-based AI inference has long been limited by operator performance and portability. By packaging kernel interfaces, tests, and implementations—and crowdsourcing benchmarks—Hugging Face is pushing WebGPU from "works" toward "engineerable optimization."
