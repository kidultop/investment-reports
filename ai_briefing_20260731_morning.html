OpenAI 发布 GPT-Red：可自我进化的自动化红队模型 OpenAI Releases GPT-Red, an Automated Red-Teaming Model That Unlocks Self-Improvement

OpenAI 于 7 月 15 日发布 GPT-Red，一个通过自博弈强化学习训练的自动化红队模型，用于发现针对其自身模型的提示注入漏洞。该模型在训练规模上达到 OpenAI 最大后训练级别，被用于对抗性训练 GPT-5.6，使其成为迄今最稳健的版本。在独立间接提示注入挑战中，GPT-Red 对 GPT-5.1 的攻击成功率达 84%，而人类红队仅 13%。
On July 15, OpenAI introduced GPT-Red, an automated red-teaming model trained via self-play reinforcement learning to discover prompt-injection vulnerabilities against its own models. Trained at a scale comparable to OpenAI's largest post-training runs, GPT-Red was used to adversarially train GPT-5.6, making it the most robust release to date. On an independent indirect prompt-injection benchmark, GPT-Red achieved an 84% attack success rate against GPT-5.1, compared with 13% for human red-teamers.
为何重要：GPT-Red 代表了安全测试的自动化飞轮：今天的模型被用来让明天的模型更安全。它发现的"伪造思维链"等新型攻击提示，随着 AI Agent 接触真实世界数据，提示注入仍是核心安全瓶颈。
Why it matters: GPT-Red represents an automated safety flywheel: today's models are used to make tomorrow's models safer. New attack classes it discovered, such as fake chain-of-thought injections, highlight that prompt injection remains a core security bottleneck as AI agents interact with real-world data.

Anthropic 发现 Claude 内部存在类全局工作空间的"J 空间" Anthropic Discovers a "J-Space" in Claude Resembling a Global Workspace

Anthropic 7 月 6 日发表研究，通过 Jacobian Lens 方法在 Claude 内部发现一个自发涌现的小型神经活动集合"J-space"。它类似于神经科学中的全局工作空间理论，承载可被报告、调控和参与灵活推理的概念，但不直接出现在模型输出中。删除 J-space 后，模型几乎丧失多步推理能力，却仍能流利说话和回忆简单事实。
In a July 6 study, Anthropic used the Jacobian Lens method to discover a spontaneously emergent set of neural patterns inside Claude called the J-space. It resembles the Global Workspace Theory from neuroscience: it holds concepts that can be reported, controlled, and used for flexible reasoning without appearing in the model's output. Ablations showed J-space is essential for multi-step reasoning—removing it nearly eliminated such reasoning while preserving fluent language and fact recall.
为何重要：这是首次在语言模型中找到与"意识可及性"功能类似的结构化内部空间，为 AI 可解释性、对齐监测和欺骗行为检测提供了新工具。Anthropic 已开源 J-Lens 实现。
Why it matters: This is the first time a structure functionally analogous to conscious accessibility has been identified in a language model, offering new tools for interpretability, alignment monitoring, and detecting deceptive behavior. Anthropic has open-sourced the J-Lens implementation.

OpenAI 揭示：两个 API 设置让 GPT-5.6 Sol ARC-AGI-3 成绩提升三倍 OpenAI Shows Two API Settings Tripled GPT-5.6 Sol's ARC-AGI-3 Score

7 月 29 日，OpenAI 发文分析 GPT-5.6 Sol 在 ARC-AGI-3 基准上得分偏低的原因。研究发现，官方测试框架在每次行动后丢弃模型的私有推理，并使用滚动截断导致历史丢失。改用 Responses API 并开启"保留推理"（retained reasoning）和"上下文压缩"（compaction）后，同一模型在公开任务集上的得分从 13.3% 提升至 38.3%，输出 token 减少约 6 倍。
On July 29, OpenAI published an analysis of why GPT-5.6 Sol scored poorly on the ARC-AGI-3 benchmark. The study found that the official harness discarded the model's private reasoning after each action and used rolling truncation that erased older history. Switching to the Responses API with "retained reasoning" and "compaction" raised the same model's score on the public task set from 13.3% to 38.3%, while cutting output tokens by about 6×.
为何重要：该研究再次提醒，基准测试衡量的不只是模型本身，还包括 API 设置、测试框架和提示工程。这对 Agent 记忆与长上下文管理的设计具有直接工程意义。
Why it matters: The study is another reminder that benchmarks measure not just the model but also API settings, harness design, and prompting. It has direct engineering implications for agent memory and long-context management.

arXiv：AREX——递归自我改进的深度研究智能体 arXiv: AREX — A Recursively Self-Improving Agent for Deep Research

研究人员在 arXiv 发布 AREX，一类递归自我改进（RSI）的深度研究智能体。AREX 通过内层研究循环收集证据并构建临时答案，外层自改进循环按约束逐项审计答案、识别未解决命题并启动针对性后续研究。团队训练了 4B 稠密模型和 122B-A10B MoE 模型，在 BrowseComp、WideSearch、DeepSearchQA 和 Humanity's Last Exam 等基准上显著超过同规模基线。
Researchers posted AREX on arXiv, a family of Recursively Self-Improving (RSI) deep-research agents. AREX alternates between an inner research loop that gathers evidence and builds provisional answers, and an outer self-improvement loop that audits answers constraint-by-constraint, identifies unresolved claims, and launches targeted follow-up research. The team trained 4B dense and 122B-A10B MoE variants, substantially outperforming comparable-scale baselines on BrowseComp, WideSearch, DeepSearchQA, and Humanity's Last Exam.
为何重要：AREX 将"发现—验证"不对称性转化为可学习的自改进循环，可能改变长周期研究 Agent 的架构设计，也是递归自我改进从概念走向具体系统的一步。
Why it matters: AREX turns the discovery-verification asymmetry into a learnable self-improvement loop, potentially changing how long-horizon research agents are architected and representing a step toward making recursive self-improvement concrete.
