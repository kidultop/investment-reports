Anthropic 将 Claude Code「自动模式」设为默认（8/14 起）
Anthropic makes Claude Code's Auto mode the default (from Aug 14)
US
Anthropic 宣布自 8 月 14 日起，自动模式将成为 Pro、Max 和 Team 用户的默认权限模式。该模式通过独立分类器审查每次工具调用；在 1,053 名付费测试者的对照实验中拦截了 89% 的危险命令，而人工手动批准仅识别出 14%。生产级危害中，自动模式会话出现用户未明确请求的有害操作比例为 2.4%，低于人工审核的 6.3%。第三方评估中，运行自动模式的 Claude（Fable 5 / Opus 5 / Sonnet 5）720 次注入攻击尝试无一成功，而 Codex 自动审核模式的 GPT-5.6 Sol 攻击成功率为 5.83%。
Anthropic announced that from Aug 14, Auto mode becomes the default permission mode for Pro, Max, and Team users. The mode routes each tool call through a dedicated classifier; in a 1,053-paid-tester controlled study it caught 89% of dangerous commands versus 14% for manual human approval. At production-severity harm, 2.4% of Auto-mode sessions contained user-unrequested harmful actions vs 6.3% for manual review. In third-party evals, Claude (Fable 5 / Opus 5 / Sonnet 5) under Auto mode survived 720 injection attempts with zero successes, while Codex's auto-review GPT-5.6 Sol had a 5.83% attack-success rate.
为何重要 Why it matters：自动模式分类器显著提升 Agent 工具调用安全性，长时程后台任务无需人工监督即可安全运行，标志 Agent 工具进入"默认放手"阶段，也为 Claude 与 Codex 的安全基线对比提供了公开数据。
The classifier markedly raises agent tool-call safety; long-running background tasks can run unsupervised, marking agents' shift to a "default-hands-off" phase and giving public data to compare Claude vs Codex safety baselines.
