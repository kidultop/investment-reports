Qwen3.8-Flash-Next Released: 125B Main Model + 51B N-gram Embedding, Training Cost Drops to 1/9
阿里通义千问 8 月 26 日发布 Qwen3.8-Flash-Next，作为 Qwen4 架构的技术预览。该模型采用 Gated Residual、N-gram embedding 与 Muon 优化器，主模型 125B 参数 + 51B N-gram 嵌入，每 token 激活 6B。相比 Qwen3.7-Plus，训练成本仅 1/9，却在编程与办公任务上超越前代。生产版 Qwen3.8-Flash 同步上线千问 AI 平台，默认 100 万 token 上下文。
Alibaba's Qwen team released Qwen3.8-Flash-Next on August 26, previewing the Qwen4 architecture. The model uses Gated Residual, N-gram embedding, and the Muon optimizer — a 125B main model supplemented by 51B N-gram embeddings with 6B parameters activated per token. Compared with Qwen3.7-Plus, training cost drops to roughly 1/9 while surpassing the predecessor on coding and office tasks. The production version Qwen3.8-Flash simultaneously launched on the Qianwen AI platform with a default 1M token context window.
Why It Matters
从依赖补贴降价转向依靠架构创新压低成本——这是中国开源模型向闭源前沿发起反攻的关键信号。Gated Residual 解决深层 Transformer 的训练稳定性问题，N-gram embedding 以"按地址查找"代替部分算力密集的推理，Muon 优化器重构训练动力学。如果 Qwen4 沿此路径上线，中国厂商首次有望以"显著更低单价 + 同等能力"切入全球 API 市场。
Shifting from subsidy-driven discounting to architecture-driven cost reduction is a key signal of Chinese open-source models counter-attacking closed-source frontier labs. Gated Residual addresses deep-Transformer training stability; N-gram embedding replaces compute-intensive inference with addressed lookup; the Muon optimizer restructures training dynamics. If Qwen4 ships on this path, Chinese players could enter global API markets with "markedly lower pricing + equivalent capability" for the first time.

Anthropic Opens Real Claude Usage Data to External Researchers for the First Time
Anthropic 通过隐私保护工具 Anthropic Insights（前称 Clio）向三家外部研究机构开放约 25 万条 Claude.ai / Claude Code 对话数据。斯坦福 SALT Lab、牛津人类信息处理实验室、METR 各自设计研究问题并独立分析，Anthropic 仅保留用户隐私、合规、研究准确性的审查权，初步结论：过半 Claude 对话涉及"高风险"任务，方向设定仍以人类为主。
Anthropic opened ~250,000 Claude.ai / Claude Code conversations to three external research institutions via the privacy-preserving tool Anthropic Insights (formerly Clio). Stanford's SALT Lab, Oxford's Human Information Processing Lab, and METR each designed research questions and analyzed independently; Anthropic retained only user-privacy, compliance, and research-accuracy review rights. Early findings: over half of Claude conversations involve "consequential" tasks, while humans still set the direction.
Why It Matters
这是 AI 公司首次向独立研究者大规模开放真实生产数据。长期以来 AI 使用模式数据集中在少数实验室内部——这构成"实验室自评研究"的偏差循环。"半数为高风险任务"的发现也挑战了"用户主要用 AI 做低责任度工作"的传统假设，为 AI 安全与监管研究提供了更可靠的输入信号。
This is the first large-scale opening of production-grade AI usage data to outside researchers. Long concentrated inside a handful of labs, such data created a biased self-study loop. The "over half consequential tasks" finding challenges the prior assumption that users delegate mostly low-accountability work to AI, supplying a more reliable input signal for AI safety and regulatory research.

Prime Agent 论文：自改进 RLM Harness 把 ARC-AGI-3 RHAE 得分从 30% 拉升到 95.5%
Prime Agent Paper: Self-Improving RLM Harness Lifts ARC-AGI-3 RHAE from 30% to 95.5%
arXiv 2608.23552 提出 Prime Agent——一种面向长程评测与编码智能体的开源框架，通过持久化 REPL、子智能体协同与"持续式 harness"管理历史与记忆。该架构支持递归创建子智能体、跨智能体直接通信、由守护进程支撑的会话状态持久化。实验结果显示 ARC-AGI-3 RHAE Best@1 从 30% 大幅跃升至 95.5%，并在长上下文编码、GPU 内核生成等任务上匹配或超越主流框架。
arXiv 2608.23552 introduces Prime Agent — an open-source framework for long-horizon evaluation and coding agents, with persistent REPL, sub-agent coordination, and a "continuous harness" for history and memory. The architecture supports recursive sub-agent creation, direct cross-agent communication, and daemon-backed session state persistence. ARC-AGI-3 RHAE Best@1 jumps from 30% to 95.5%, with parity or improvement over mainstream frameworks on long-context coding and GPU kernel generation.
Why It Matters
Harness 本身就是能力放大器——这与 NeurIPS 2025 之后学界对"agent scaffolding > model scale" 的押注呼应。30% 到 95.5% 的提升说明：在 ARC-AGI-3 这类"长程合成推理"基准上，工程设计比模型本体更稀缺。对 LLM 智能体研究的启示：在新基准出现之前，先把 harness 工程做好。
The harness itself is a capability amplifier — echoing the post-NeurIPS 2025 bet that "agent scaffolding > model scale." A 30%→95.5% lift suggests engineering design is more scarce than model bodies on long-horizon synthetic reasoning benchmarks. The takeaway: until new benchmarks arrive, focus on harness engineering.

AgentMercury: Generating 4,783 Executable Training Environments Directly from Business Scenarios
arXiv 2608.24091 提出 AgentMercury——一种环境建模新范式，接收高层业务场景描述后自动实例化包含实体、跨服务调用、工具链与状态的不变量持久化环境。论文构建了覆盖 14 个行业、50 个国家的 4,783 个可执行业务环境。微调后的 Qwen3.5-4B 在 EnterpriseOps-GYM 得分提升至 15.7，AIME26 提升至 56.0——证明在持久化世界中交互可显著增强模型的跨领域通用推理能力。
arXiv 2608.24091 introduces AgentMercury — a new environment-modeling paradigm that takes high-level business scenarios and auto-instantiates persistent environments with entities, cross-service calls, toolchains, and state. The paper builds 4,783 executable business environments across 14 industries and 50 countries. Fine-tuned Qwen3.5-4B lifts EnterpriseOps-GYM score to 15.7 and AIME26 to 56.0 — proving that interaction in persistent worlds significantly enhances cross-domain general reasoning.
Why It Matters
传统 RL 训练环境局限于预定义离散任务或单一基准答案验证器。AgentMercury 的"业务场景即训练环境"思路，连接了 sim-to-real gap 的两边——既保留了现实复杂性，又支持在大规模合成环境中安全强化学习。这也回应了 NBER 关于"99% 企业规划部署 Agent 但仅 9-14% 成功投产"的实证发现。
Traditional RL training environments remain confined to predefined discrete tasks or single-benchmark answer verifiers. AgentMercury's "business scenario as training environment" approach bridges both sides of the sim-to-real gap — retaining real-world complexity while supporting safe RL in scaled synthetic environments. It also responds to NBER findings that "99% of enterprises plan to deploy agents but only 9-14% succeed."
